# HARUMVERSO NODE

Harumverso is registered as a **content / knowledge / publishing node** in the broader Harum ecosystem.

## Canonical endpoints

- Public code: https://github.com/suryamayaharum-droid/astro-blog-starter-template
- Operational blueprint: private HIVE → `docs/HARUMVERSO_BLUEPRINT.md`
- Memory namespace: `suryamayaharum-droid/mempalace/HARUMVERSO.md`
- Radar: Google Sheet maintained by the editorial research workflow.

## Node responsibilities

```
discover → verify → relate → curate → publish
```

### Inputs
- public web sources;
- official artist channels/sites;
- public-domain archives;
- user-owned Arte Harum / Studio 23 assets.

### Outputs
- creator cards;
- reference trails;
- outlier analysis;
- classic-master bridges;
- Harum Noir exercises;
- public newsletter/RSS.

## Safety / governance

This node does not autonomously purchase, sell, publish to commercial platforms or impersonate artists.
External publication and commerce remain behind explicit write gates.
Copyrighted artwork is referenced/embedded from legitimate sources rather than copied into the mesh.

## Relationship

Global Mesh is a routing/discovery layer. It must not duplicate the Harumverso catalog; link to the canonical data instead.
